<objective>
Two small additions:

1. **validate.sh**: When the `COOLIFY_HISTORY_SUGGESTIONS` environment variable is set (to a temp file path by provision.sh), append newline-delimited JSON objects for each `warn "env_vars: ..."` and `fail "MISSING:KEY:ENV (... TODO_REPLACE...)"` finding. This surfaces stale/placeholder Doppler key findings as cleanup_suggestions in the history entry written by provision.sh's trap.

2. **init.sh**: After writing `./coolify.yaml`, append `.coolify/` to `.gitignore` if the line is not already present. The `.coolify/` directory holds runtime artifacts (history file, hooks) that should not be committed.

Purpose: Completes the provision history feature — cleanup suggestions flow from validate.sh to the history writer; new repos get .gitignore protection for the runtime artifacts directory.

Output: Modified `scripts/validate.sh` (opt-in suggestion writing) and `init/init.sh` (gitignore append).
</objective>

  <action>
Make two targeted additions to `scripts/validate.sh`. Both are opt-in via `${COOLIFY_HISTORY_SUGGESTIONS:-}` — when the env var is unset, no behavior changes.

**Addition A — env_vars grep scan stale-key finding (line ~245):**

Locate this block (the env_vars grep scan loop body, inside the `if [ -d "$YAML_DIR/.git" ]` block):

```bash
      warn "env_vars: $_gk declared in coolify.yaml but not found in codebase (stale?)"
```

Immediately after that `warn` line, insert:

```bash
      if [ -n "${COOLIFY_HISTORY_SUGGESTIONS:-}" ]; then
        printf '{"type":"stale_env_var","key":"%s","detail":"declared in coolify.yaml but not found in codebase grep scan"}\n' \
          "$_gk" >> "$COOLIFY_HISTORY_SUGGESTIONS"
      fi
```

**Addition B — Doppler TODO_REPLACE placeholder finding (line ~266):**

Locate this block (inside the Doppler key check loop, the `if [ "$RC" = "2" ]` branch):

```bash
        fail "MISSING:$KEY:$ENV (present but value is TODO_REPLACE_BEFORE_DEPLOY)"
```

Immediately after that `fail` line, insert:

```bash
        if [ -n "${COOLIFY_HISTORY_SUGGESTIONS:-}" ]; then
          printf '{"type":"placeholder_value","key":"%s","detail":"value is TODO_REPLACE_BEFORE_DEPLOY in Doppler %s config"}\n' \
            "$KEY" "$ENV" >> "$COOLIFY_HISTORY_SUGGESTIONS"
        fi
```

That is all. Do NOT add suggestion writes for any other `fail` or `warn` calls — only these two categories map to cleanup_suggestions per the locked CONTEXT.md schema.

**Why `>> "$COOLIFY_HISTORY_SUGGESTIONS"` is safe:** provision.sh creates this file with `mktemp` before calling validate.sh, so the file always exists when the env var is set. The `>>` append is non-destructive if validate.sh finds no issues.

  <action>
Add a `.gitignore` append guard to `init/init.sh`.

**Location:** After the `echo "WROTE ./coolify.yaml"` line (line 182 — the first occurrence, right after the YAML validation block), before the `=== Generating .github/workflows/deploy.yml ===` section.

Find the exact block:
```bash
echo ""

echo ""

# FINAL STEP: invoke generate-workflow.sh ...
```

Insert between `echo "WROTE ./coolify.yaml"` and the `echo ""` that precedes `# FINAL STEP`:

```bash
# Add .coolify/ to .gitignore — runtime artifacts directory, not committed config.
# grep -qxF: exact full-line match; -F treats as literal; 2>/dev/null handles missing .gitignore.
if ! grep -qxF '.coolify/' ./.gitignore 2>/dev/null; then
  printf '\n# claude-skills-deploy runtime artifacts\n.coolify/\n' >> ./.gitignore
  echo "UPDATED .gitignore (+.coolify/)"
fi
```

**Why this location:** The `./coolify.yaml` file has just been written and validated. The idempotent guard at lines 22-26 exits early if `coolify.yaml` already exists, so this block is never reached on re-init — it only runs on first init. The `grep -qxF` guard makes the gitignore append safe if `init.sh` is ever made re-runnable in future.

**Note:** Do NOT add `mkdir -p .coolify/` — the `.coolify/` directory is created by `provision.sh` on first run, not by init. Init only ensures git won't track it when it appears.
